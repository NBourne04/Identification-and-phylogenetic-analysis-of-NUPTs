# Identification and Phylogenetic Analysis of NUPTs

This repository contains the scripts used to **identify candidate nuclear plastid DNA sequences (NUPTs)** and perform **phylogenetic analyses to assess their potential lateral (horizontal) acquisition**.

The scripts are numbered according to the order in which they should be run. The **NUPT Identification Pipeline must be completed before running the NUPT Phylogenetic Pipeline**, as the latter uses candidate NUPT sequences generated by the identification pipeline.

## NUPT Identification Pipeline

This pipeline identifies candidate NUPTs by comparing nuclear genomic sequences with plastid sequences.

### 01-makeblastdb.sh

Creates BLAST databases from the nuclear genomes.

### 02.1-self_blast.sh

Performs BLAST searches of each species' own chloroplast genome against its nuclear genome to identify nuclear regions homologous to the species' own chloroplast genome.

### 02.2-Foreign_chloroplast_blast.sh

Performs BLAST searches of foreign chloroplast genomes against the nuclear genome to identify nuclear regions homologous to chloroplast sequences from other species.

### 03-filter_blast_hits.sh

Filters the self and foreign BLAST results to retain hits that are **≥1 kb in length and ≥95% identical**.

### 04-compare_chloroplast_blasts.py

Compares the filtered self and foreign chloroplast BLAST hits to identify candidate foreign NUPTs. Candidate regions are retained when the **foreign chloroplast hit has a bitscore >100**.

### 05-extract_foreign_NUPT_regions.sh

Extracts the candidate foreign NUPT regions identified in the previous step as FASTA sequences. These sequences are used as input for the NUPT Phylogenetic Pipeline.

## NUPT Phylogenetic Pipeline

This pipeline assesses the phylogenetic relationships of candidate NUPTs to chloroplast sequences from related species.

### 01-makeblastdb.sh

Creates BLAST databases from chloroplast genomes.

### 02-blastn_loop.sh

Searches the candidate NUPT sequences against the chloroplast BLAST databases using BLASTN.

### 03-filter_and_merge_1000bp_blasts.sh

Filters the BLAST hits using `03-extract_best_hsp.py`. Hits are first filtered by **alignment length (>1 kb)** and orientation, with the highest cumulative bitscore and alignment length used to identify the best-supported hit. The best hit for each chloroplast genome is then retained based on **bitscore and alignment length**.

### 04-align_blast_regions.sh

Aligns the selected chloroplast regions and candidate NUPT sequences using MAFFT to generate multiple sequence alignments.

### 05-iqtree_Array.sh

Constructs maximum-likelihood phylogenetic trees from the MAFFT multiple sequence alignments using IQ-TREE.

### label_trees_v2.py

Labels chloroplast accessions in the resulting phylogenetic trees with their corresponding species names.
